Ordenamiento Burbuja en Java
Descripción

Este proyecto es una práctica de programación en Java donde se implementan dos formas de ordenar números: el método burbuja normal y el método burbuja mejorado.

Objetivo

Aprender cómo funcionan los métodos de ordenamiento y conocer la diferencia entre la versión normal y la optimizada.

Métodos utilizados
Burbuja normal: compara números consecutivos y los intercambia cuando están desordenados.
Burbuja mejorado: utiliza una variable booleana para detectar si hubo intercambios y detenerse cuando el arreglo ya está ordenado.
Pruebas

El programa utiliza arreglos desordenados y parcialmente ordenados para comprobar los resultados de ambos métodos.

Lenguaje

Java

Cómo ejecutar
Abrir el proyecto en Apache NetBeans.
Abrir la clase OrdenamientoBorbuja.
Ejecutar el archivo y revisar los resultados en la consola.
